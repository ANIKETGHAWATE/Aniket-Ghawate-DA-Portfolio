# Aniket Ghawate — Data Analyst Portfolio

This is a lightweight static website made with HTML, CSS, and JavaScript.

## Open on Windows
1. Extract this ZIP file.
2. Open the extracted `Aniket_Ghawate_Portfolio` folder.
3. Double-click `index.html` to open the website in your browser.

You do not need Node.js, npm, React, Vite, or any package installation.

## Files
- `index.html` — website content
- `css/style.css` — styling and layout
- `js/script.js` — navigation interactions

Keep the folders and files together in their current structure.

## Edit in VS Code
Open the extracted folder in VS Code. Edit `index.html`, `css/style.css`, or `js/script.js`, save with Ctrl+S, and refresh your browser.

## Before sharing
Replace the placeholder email and sample social links in `index.html` with your real details. Review all project and work-experience descriptions for accuracy.

## Deploy free with GitHub Pages
Upload the extracted files and folders (not the ZIP itself) to a public GitHub repository. In Settings → Pages, choose “Deploy from a branch”, select `main` and `/(root)`, then save.
